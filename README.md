
# Windows Server 2019 - Active Directory Home Lab

## Overview
This project documents my experience setting up and configuring a Windows Server environment using Oracle VirtualBox.

The purpose of this lab is to develop practical IT administration skills and gain hands-on experience with Microsoft Active Directory.

## Technologies Used
- Windows Server 2019
- Oracle VirtualBox
- Active Directory Domain Services (AD DS)
- DNS
- Group Policy Management

## Lab Objectives
- Install and configure Windows Server.
- Set up Active Directory Domain Services.
- Create and manage domain user accounts.
- Organize users using Organizational Units.
- Configure security groups and permissions.
- Explore Group Policy management.
- Join a client computer to the domain.
